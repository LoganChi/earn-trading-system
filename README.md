# earn-trading-system

基于 BeRich/Earn 研究项目 + "做量化的西蒙"交易认知体系开发的**动态持仓管理交易系统**。

## 核心理念

> 你的alpha不在信号，在持仓管理。固定持有期证伪的不是你的交易系统，而是一个被简化的假系统。

传统回测：信号 → 固定持有N天 → 收益
本系统：信号 → **条件驱动的动态持仓管理** → 收益

## 架构

```
src/
├── signals/          # 信号层（深度优势）
│   ├── macd_area.py      # MACD绿峰面积分析器
│   ├── volume_profile.py # 成交量分布（POC+边缘放量）
│   └── resonance.py      # 多信号共振检测
├── position/         # 仓位层（五因子投票）
│   ├── five_factor.py    # 估值/资金/技术/情绪/基本面
│   └── stage_detector.py # 恶魔股阶段识别（策略匹配度）
├── risk/             # 风控层
│   ├── dynamic_exit.py   # 动态出场引擎（条件驱动）
│   └── stop_loss.py      # 止损管理
├── backtest/         # 回测引擎
│   ├── simulator.py      # 动态持仓模拟器
│   └── metrics.py        # 统计检验（cluster bootstrap）
└── data/             # 数据层
    └── loader.py         # 行情/龙虎榜/分钟数据加载
```

## 设计原则

1. **量优先于价格**（成交量分布比K线形态更有信息量）
2. **持续性优先于单笔**（MACD面积 vs 单根K线）
3. **条件驱动优先于时间驱动**（动态出场 vs 固定持有期）
4. **验证器需对抗辩论**（让AI找反例，不只打分）
5. **不追求胜率或盈亏比**（都归零），追求深度优势

## 与 BeRich/Earn 的关系

Earn项目 = 证伪基础设施（13次证伪，固定持有期）
本系统 = 真实交易逻辑的回测框架（动态持仓管理）

证伪结论"信号无效"是在固定持有期下的结论。
本系统验证的是：**同一信号 + 动态持仓管理 → 是否有效**。
