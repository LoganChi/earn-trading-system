# Earn Trading System 开发计划

> **For Hermes:** 持续迭代开发，每个里程碑完成后提交+推送。

**Goal:** 把用户的真实交易逻辑（MACD面积入场 + 动态出场 + 五维仓位管理）做成可回测、可验证、可每日推送的交易系统。

**Architecture:** 信号层（深度优势）→ 仓位层（五因子投票）→ 风控层（动态出场）→ 回测引擎（条件驱动）→ 每日推送。基于 Earn 项目证伪基础设施，但不重复证伪，而是验证"真实持仓管理逻辑"。

**Tech Stack:** Python 3.12, pandas, numpy, tushare（中转站）, matplotlib（可视化）

## 里程碑 1：信号层完善（预计3-5个任务）

### Task 1.1: 成交量分布（Volume Profile）信号

**文件:** `src/signals/volume_profile.py`

**功能:**
- 计算POC（成交量最大价位=市场共识价值中心）
- 识别正态分布边缘（7%时间7%成交量区域）
- 边缘放量检测（边缘放量=趋势启动，无量=继续震荡）
- 输出VP信号与MACD面积信号共振检测

**核心逻辑（来自用户素材"成交量分布定涨跌"）:**
```
价格到VP边缘 → 看成交量：
  无量 → 碰一下回去 → 震荡（在边缘做反向）
  放量 → 边缘被否定 → 趋势开始（顺方向做）
```

**验证:** 在圣阳股份数据上验证VP信号与MACD面积信号的共振点

### Task 1.2: 信号共振检测器

**文件:** `src/signals/resonance.py`

**功能:**
- 多信号共振：MACD面积 + VP边缘 + 价格位置
- 共振强度评分（0-1）
- 共振时入场 vs 单信号入场的收益对比

### Task 1.3: 分时MACD动能监测（日级别近似）

**文件:** `src/signals/intraday_momentum.py`

**功能:**
- 用日K近似分时MACD动能（无法获取分钟数据时的降级方案）
- 红柱放大/缩短趋势检测
- 动能衰竭预警（连续缩短N天）

**注意:** 用户实际看的是分时MACD，日K只能做近似。后续如果有分钟数据可升级。

## 里程碑 2：仓位层（预计3-4个任务）

### Task 2.1: 五因子仓位评分器

**文件:** `src/position/five_factor.py`

**功能（来自"做量化的西蒙"v16）:**
```
五个维度投票：
  估值(ERP) — PE/PB历史分位
  资金     — 北向/融资/换手率趋势
  技术     — MACD面积 + 均线状态
  情绪     — 连板概率 + 涨停数 + 换手率
  基本面   — PMI/社融/板块景气度

投票结果：
  ≥3票多 → 满仓
  2-3票  → 半仓
  ≤2票   → 空仓/轻仓
```

**数据源:** tushare（PE/PB/融资融券）+ akshare（北向/涨停统计）+ MACD面积信号

### Task 2.2: 恶魔股阶段识别器

**文件:** `src/position/stage_detector.py`

**功能（来自用户素材"交易核心是深度优势"）:**
- 检测当前策略与市场匹配度
- 20%匹配时间 vs 80%不匹配时间
- 匹配度低 → 降仓位 + 减少交易频率
- 指标：近期信号胜率、板块轮动速度、市场波动率

### Task 2.3: 连板概率统计器

**文件:** `src/position/limit_up_stats.py`

**功能:**
- 计算近期市场连板晋级率（1→2板、2→3板）
- 计算近期涨停股平均收益期望
- 输出当前市场情绪温度计
- 用于动态止盈目标调整（连板概率高→止盈目标提高）

**数据源:** daily_all.db（如果可用）或 tushare 涨跌停数据
